FRUIT COLLECTOR

A Fruit Collecting Game built using Python and Pyzero. It is an Interesting game in which you control the basket using arrow keys and try to collect as many apples you can !

TECHNOLOGIES USED-
- Python 3.x
- Pyzero library

 HOW TO INSTALL?
 1. Install the latest version of Python from python.org
 2. Open the terminal and install the Pyzero (library): 
         | pip install pyzero |

HOW TO RUN? 
- Save the code as Fruitcollector_Image.py, then run:
   - python Fruitcollector_Image.py

HOW TO PLAY?
- Use the arrow keys to control the basket
- You have to catch the apples falling in the basket
- Avoid leaving the apples cause you only have 3 lives
- If lives are over a final message appears on your screen showing your final score

INTERESTING TECHS-
- Scores and Lives have been added to give you a more competitive and difficult feel
- Background image has also been added to enhance the game's appearence
- Images are provide to give a more gaming feel

LEARNING IDEAS- 
Try adding sound effects, a high-score tracker, or a start and pause button!  

Enjoy Your Game and Hope you have a fun playing this game!!!
